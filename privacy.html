Privacy Policy 隱私權政策

Last updated 最後更新：2026-10-12

1. Who we are 我們是誰

Laugh in a Blink 秒笑 ("we") runs a short-video channel on Instagram, Facebook, YouTube and TikTok. We operate an internal publishing tool ("the Tool") that uploads videos we produce to accounts we own.

Laugh in a Blink 秒笑（下稱「我們」）在 Instagram、Facebook、YouTube、TikTok 經營短片頻道，並使用內部發布工具（下稱「本工具」）把我們製作的影片上傳到我們自己的帳號。

2. What data the Tool accesses 本工具存取哪些資料

  • Access tokens for our own accounts, granted through each platform's official authorization (OAuth).
  • Basic profile information of our own accounts (account ID, name) needed to publish.
  • Publishing status and basic statistics of videos we posted.

本工具只存取：經各平台官方授權（OAuth）取得的、我們自己帳號的存取權杖；發布所需的我們帳號基本資料（帳號 ID、名稱）；以及我們發布影片的狀態與基本數據。

The Tool does not collect, store or process personal data of viewers or any other users.

本工具不會收集、儲存或處理觀眾或任何其他使用者的個人資料。

3. How we use it 如何使用

Solely to upload, schedule and publish our own videos and to check whether they were published successfully. We do not sell, rent or share data with third parties, and we do not use it for advertising.

僅用於上傳、排程、發布我們自己的影片，並確認是否發布成功。我們不出售、出租或分享資料給第三方，也不用於廣告。

4. Storage & security 儲存與安全

Tokens are stored in encrypted secret storage (local environment files and GitHub encrypted secrets) and are never published in source code. Only our team can access them.

權杖存放在加密的機密儲存（本機環境檔與 GitHub 加密 Secrets），不會出現在程式碼中，只有我們團隊能存取。

5. Google / YouTube

The Tool uses YouTube API Services. By using our YouTube channel features you also agree to the YouTube Terms of Service, and the Google Privacy Policy applies. You can revoke the Tool's access at any time from Google security settings.

本工具使用 YouTube API 服務，適用 YouTube 服務條款與 Google 隱私權政策。可隨時在 Google 安全性設定撤銷本工具的存取權。

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. TikTok

The Tool uses the TikTok Content Posting API only to post videos to our own TikTok account. Access can be revoked at any time in TikTok's app settings (Security → Manage app permissions).

本工具只透過 TikTok Content Posting API 把影片發布到我們自己的 TikTok 帳號，可隨時在 TikTok 設定中撤銷授權。

7. Meta (Instagram / Facebook)

The Tool uses the Instagram Graph API and Facebook Pages API only for our own Instagram professional account and Facebook Page.

8. Data retention & deletion 保存與刪除

We keep tokens only while the Tool is in use and delete them when access is revoked. To request deletion of any data, email us at the address below; we respond within 30 days.

權杖只在使用期間保存，撤銷授權後即刪除。如需刪除任何資料，請寄信給我們，30 天內回覆。

9. Children 兒童

The Tool is not directed to children under 13 and does not knowingly collect their data.

10. Changes 變更

We may update this policy; changes are posted on this page with a new date.
